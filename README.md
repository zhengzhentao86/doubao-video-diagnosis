# 短视频拆解学习 Skill 使用指南

> 给你一个工具：丢一条抖音视频链接给它，它自动帮你拆出这条视频为什么火、你下一条怎么照着做。

---

## 这个工具能帮你做什么？

你有没有过这种情况：

- 刷到一条卖货视频，拍得真好，想知道它到底好在哪？
- 想模仿一条爆款，但不知道从哪学起？
- 自己拍的视频数据不好，但不知道问题出在哪？

这个工具就是帮你干这个的。

**你只需要做一件事：把抖音视频链接发给它。**

然后它会自动帮你：
1. 下载这条视频
2. 拆解每一秒的镜头和文案
3. 分析它为什么能让人停下来、看下去、相信、下单
4. 给你一份「拆解学习报告」，告诉你这条视频最值得学的是什么

---

## 怎么用？（三步搞定）

### 第一步：把 Skill 安装到豆包里

把 `doubao-video-diagnosis` 这个文件夹，放到你的豆包 skills 目录里就行。

> 具体路径：你电脑上豆包的 skills 文件夹，把整个文件夹复制进去就好。
> 不会找的话，问一下课程助教～

---

### 第二步：打开豆包，直接说人话就行

安装好之后，你在豆包对话框里，直接发这句话：

```
帮我拆解这条视频：
https://www.douyin.com/video/xxxxxxxxx
```

就这么简单。你不用懂任何技术，不用写代码，就像平时跟朋友说话一样。

---

### 第三步：等它出报告，然后打开看

大概等 3-5 分钟（视频越长等越久），它会给你一个 HTML 文件。

你用浏览器打开这个文件，就能看到完整的拆解报告了。

---

## 报告里有什么？

你打开报告之后，会看到这几个部分：

### 🎬 原片回放
视频直接嵌在报告里，边看边对照分析。

### 一、为什么停下来？
它会告诉你：这条视频前 3 秒用了什么钩子，为什么能让你不划走。
然后告诉你：**下一条视频你可以怎么学这个钩子。**

### 二、为什么看下去？
它会拆解：这条视频的节奏是怎么设计的，卖点是怎么排布的。
然后告诉你：**这个节奏你下一条怎么套用。**

### 三、为什么相信？
它会分析：这条视频用了什么方法让观众相信它说的是真的。
然后告诉你：**这种"让人相信"的结构你怎么复制。**

### 四、为什么行动？
它会拆解：结尾是怎么引导观众下单/进直播间的。
然后告诉你：**你的结尾可以怎么设计。**

### 📝 可复制脚本骨架
最后它会把整条视频的结构，提炼成一个你可以直接套的脚本模板。
你把产品换成你自己的，照着这个框架写就行。

## 常见问题

### Q：我可以用本地视频文件吗？
A：可以。你直接把视频文件拖进对话框发给它就行。

### Q：它能拆多少秒的视频？
A：一般 1 分钟以内的短视频效果最好。长一点的也能拆，就是等的时间久一点。

### Q：它拆的是好视频还是差视频？
A：都能拆。好视频帮你学结构，差视频帮你找问题。

### Q：拆完之后我能直接照着拍吗？
A：可以。报告里有「可复制脚本骨架」，你把产品换成你自己的，照着结构拍就行。

---

## 注意事项

- 拆视频需要联网，因为要调用视频理解的 AI 能力
- 第一次用可能要等久一点，后面就快了
- 如果是抖音短链接（v.douyin.com 开头的），有时候会抓不到视频，这时候你把视频下载下来，直接发文件给它就行
